Chaos Control Room

An interactive simulation of a Kubernetes platform under failure. Kill pods, inject errors, surge traffic and fail over the database, then watch SLOs, alerts, autoscaling and self-healing respond.

No login, nothing to install. It's a simulation: no real cluster runs behind this page.

Under the hood

How this maps to real infrastructure

Everything runs in your browser: a deterministic simulator stepping every 100 ms, drawn with Three.js. Each part stands in for a production component, and every "real config" button in the console shows the manifest behind it.

Next: a real backend

  1. Terraform provisions a small k3s cluster with checkout-api and a CloudNativePG database.
  2. Argo CD syncs the same manifests from Git, so a rollback is a revert.
  3. Prometheus and OpenTelemetry publish onto the event bus this page already uses, so the console works unchanged against a live cluster.
